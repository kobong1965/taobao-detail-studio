# 衣序 · 详情页工作室

用于服装电商详情页制作的 Windows 桌面软件。上传商品图片后按模板排版，支持图片分类、尺码表识别和重新排版、人工编辑，以及分段 JPG 导出。

当前版本：`0.1.7-preview`。这是 Windows x64 便携测试版。

## 下载和启动

到本仓库的 [Releases](https://github.com/kobong1965/taobao-detail-studio/releases) 下载 `yixu-detail-studio-0.1.7-preview-win-x64.zip`，完整解压到可写文件夹，双击 `YixuDetailStudio.exe` 或 `启动衣序.cmd`。运行环境已包含，无需安装 Node.js 或 Electron。请先完整解压，不要在压缩包内运行。

项目、模板、API 配置和运行缓存保存在软件文件夹的 `data` 中；默认导出位于 `data/exports`，导出时也可选择其他文件夹。备份或移动软件时保留 `data`。升级时先关闭软件，备份 `data`，再把它保留到新版本目录，避免丢失已有工程。API Key 使用 Windows 系统加密，在另一台电脑上使用时可能需要重新填写。

## 制作详情页

1. 在设置中填写自己的 OpenAI 兼容 API 地址、API Key 和支持图片识别的模型名称。模型服务由使用者自行配置，软件不提供额度。
2. 创建商品项目，将模特图、细节图、尺码表混合拖入批量上传区。软件先快速分类并填图，可信图片填入模板，不确定的图片保留供人工检查。
3. 尺码表独立在后台识别。按黑字白底模板重写数据，完整保留更多尺码和字段；腿围、常规版裤长和加长版裤长分列，模糊值留空，围度不擅自换算。请核对识别数据，表格支持手动编辑。
4. 点击图片板块，从已上传素材中选择更换；一张图片可以反复使用。图片入口支持拖入上传，单图位置一次接收一张，批量区域最多100张。图片可选择固定框或原比例。
5. 模板显示排版缩略图，支持改名、编辑并同步当前工程。模块锁定固定布局，保留换图、调整取景、改文字和填尺码功能。
6. 保存到项目库，以后可重新打开编辑。也可导出 `.yixu` 可编辑工程文件，包含当前图片和排版，工程文件不包含 API 密钥。
7. 导出 JPG 时填写名称、设置质量并选择文件夹。每张宽1440、高1920，最后一张按剩余高度输出，同名导出保留已有结果。

公开包使用自有占位素材，保留首图 → 尺码表 → 双列细节 → 模特展示的模板结构。上传自己的商品图片开始制作。公开仓库与软件包均不包含开发者个人工程、原商品照片或 API 配置。

配置完成后，批量上传会调用所配置的模型进行分类，检测到尺码图时另行调用识别；软件不自动重试付费请求。未配置 API 或服务失败时可以人工分类和填表。粗筛结果需要人工核对，具体速度取决于模型服务。

## 源码与验证

应用使用原生 JavaScript 和 Electron。纯逻辑测试使用 Node.js 自带测试运行器：

```powershell
node --test tests/*.test.mjs desktop/tests/*.test.cjs
```

从源码运行时，将 Electron 可执行程序传入并指定 `desktop` 目录；数据保存在源码的 `data` 中。公共构建脚本仅复制运行所需文件、公共占位素材和第三方许可证，排除用户数据和开发资料。

```powershell
node scripts/build-portable.cjs --source-root "完整源码路径" --runtime-root "完整Electron运行时路径" --output-root "完整构建输出路径"
```

软件不包含 Photoshop PSD 导入导出、修图、素材审核或淘宝自动发布。当前版本尚未提供自动更新或跨电脑工作台同步。
